COOP Reporting API — Test Configurations

Each link opens a test page served from https://localhost:8443 with a specific Cross-Origin-Opener-Policy (or -Report-Only) header applied by Caddy. The cross-origin target is always https://localhost:9443 (no COOP → effectivePolicy: "unsafe-none").

Theory to verify: access-to-opener and access-to-opened-window reports can only be generated under report-only mode. In enforce mode the browsing context group is severed when the popup navigates to the incompatible origin — popup.closed returns true immediately, so no cross-origin property access ever occurs and no access reports are generated. Navigation reports (navigation-from-response, navigation-to-response) go to the server endpoint in both modes.
